# Mac Mini — documentation auto-blink

For photos and video where the eyes should blink on their own (no webcam).

## Quick start

1. Copy `macmini-auto-blink.command` onto the Mac Mini (Desktop is fine).
2. First time: right-click the file → **Open** → confirm.
3. The browser opens the live Crowd Eyes page in **auto-blink** mode.

Eyes open and close sporadically every ~1.5–4 seconds, with occasional double-blinks and short stares.

## Manual URL (same thing)

If the `.command` file is awkward, just open this in any browser on the Mac Mini:

https://kamitasik.github.io/Crowd-Eyes-Interactive-Window/?auto=1

(`?blink=1` works too.)
